# Foody Delivery Back-end — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** API REST Spring Boot com cadastro/login JWT e gestão de pedidos de delivery (criar, listar, buscar, atualizar status), persistida em SQLite, com 100% de cobertura.

**Architecture:** MVC por camada (`controller → service → repository → model`), DTOs como records, regras de negócio nas entidades (`Order.changeStatus`, `OrderStatus.canTransitionTo`), segurança stateless via filtro JWT, erros padronizados por `@RestControllerAdvice`.

**Tech Stack:** Java 21 (target), Spring Boot 3.5.x, Spring Web, Spring Data JPA, Spring Security, Bean Validation, SQLite (`org.xerial:sqlite-jdbc`) + `org.hibernate.orm:hibernate-community-dialects`, jjwt 0.12.x, JUnit 5, Mockito, AssertJ, MockMvc, JaCoCo 0.8.14.

**Spec:** `docs/superpowers/specs/2026-10-16-backend-design.md`

## Global Constraints

- Código (classes, campos, rotas) em inglês; valores de `OrderStatus` exatamente `RECEBIDO, EM_PREPARO, SAIU_PARA_ENTREGA, ENTREGUE, CANCELADO`.
- Mensagens de erro da API em português.
- Pacote base `com.foody.delivery`; projeto em `backend/`.
- `maven.compiler.release` = 21; JDK local é o 25.
- Sem Lombok (getters/setters explícitos — evita ruído de cobertura).
- Cobertura JaCoCo: 100% de linhas e branches (`LINE` e `BRANCH`, `COVEREDRATIO` = `1.00`) no bundle, verificada em `mvn verify`. Sem exclusões.
- Commits: Conventional Commits em português, um por task, **sem nenhuma linha de autoria/coautoria de IA** (nada de `Co-Authored-By`, nada de "Generated with").
- Ambiente local: `JAVA_HOME` do usuário aponta para `...\jdk-25\bin` (errado). Todo comando Maven roda com `JAVA_HOME="C:/Program Files/Java/jdk-25"` prefixado (bash), sem alterar a variável global.
- SQLite com HikariCP: `maximum-pool-size: 1` (SQLite não lida bem com escrita concorrente; e banco em memória compartilhado exige uma conexão).

## Review Focus

1. **E-mail com maiúsculas/espaços no login** (`" Maria@X.com "`) — deve logar a mesma conta cadastrada como `maria@x.com`. Teste em Task 5 (`AuthServiceTest.loginNormalizesEmail`).
2. **Status inválido no PATCH** (`{"status":"PRONTO"}` ou `{}`) — 400 com mensagem clara, não 500. Teste em Task 6 (`OrderControllerIT.patchWithUnknownStatusReturns400`, `patchWithNullStatusReturns400`).
3. **Token adulterado/expirado** — 401 em JSON padrão, não 403 nem 500. Teste em Task 4 (`JwtServiceTest`) e Task 5 (`AuthControllerIT.protectedRouteWithTamperedTokenReturns401`).
4. **ID inexistente ou não numérico** (`/api/orders/999`, `/api/orders/abc`) — 404 / 400, não 500. Teste em Task 6 e Task 7.
5. **CEP com hífen** (`01310-100`) — aceito e salvo como `01310100`. Teste em Task 6 (`OrderServiceTest.createNormalizesZipCode`).
